## Исправления при повторной проверке

- Реквизиты объектов обернуты в `<Properties>` (без этого выгрузка не загружается).
- Для справочников, документов, перечислений, регистра, отчетов и обработок добавлен `InternalInfo` с `GeneratedType`.
- `ChoiceDataGetModeOnInputByString` = `Directly` (допустимое значение).
- Права роли Диспетчер: для реквизитов и табличной части `Update` заменено на `Edit`.
- ChildObjects в конфигурации выстроены по порядку конфигуратора.
- Формы: элементы в каноническом порядке, у таблиц добавлены companion-элементы (`AutoCommandBar`, `SearchStringAddition`, `ViewStatusAddition`, `SearchControlAddition`).
- Добавлена форма записи регистра ЦеныБлюд (раньше команда «Установить цену» открывала бы несуществующую форму).
- Курьер: при проверке активных заказов исключается текущий заказ (в базе он еще числится со старым статусом); активными считаются статусы Новый, Готовится, ПереданКурьеру.
- АРМ: результат `Записать()` проверяется, при отказе транзакция откатывается.
- Заказ: пустое количество при изменении строки состава становится 1.
- ChildObjects подсистем (5 шт.) и справочника КатегорииБлюд: добавлен пустой `<ChildObjects/>` (обязательный элемент по схеме).
- Регистр ЦеныБлюд: ресурс `Цена` перенесен перед измерением `Блюдо` (порядок по схеме InformationRegisterChildObjects).
- Документ Заказ: в ChildObjects форма `ФормаДокумента` перенесена перед табличной частью `Состав` (порядок по схеме DocumentChildObjects); у табличной части `Состав` добавлен `InternalInfo` с GeneratedType `DocumentTabularSection` / `DocumentTabularSectionRow`.

## Что остается до сдачи

1. Загрузить выгрузку в конфигуратор 8.5.1 («Загрузить конфигурацию из файлов») и выполнить «Проверку конфигурации» без ошибок.
2. Пройти сценарии вручную: создание заказа, авторасчет цены, блокировка блюд чужого ресторана, загрузка фото блюда, назначение курьера в АРМ, статусы курьера, отчеты.
3. Проверить каждую роль под отдельным пользователем.
4. `DefaultRoles` в Configuration.xml не заполнен намеренно: иначе все пользователи получат полные права. Роли назначаются пользователям вручную или по решению заказчика.
5. Картинки подсистем — сгенерированные PNG-заглушки; при необходимости заменить на эталонные.
6. `ConfigDumpInfo.xml` не обновлялся; при полной загрузке из файлов это не требуется.

## Примечание о проверке XSD

Официальные XSD версии 2.21 (репозиторий yellow-hammer/namespace-forest) использованы как дополнительный сигнал. Они дают ложные срабатывания на исходных файлах проекта (например, `Configuration.xml` и `Languages/Русский.xml` из первого коммита) и на опциональных элементах форм, поэтому не считаются авторитетными. Выбраны валидаторы cc-1c-skills, которые сверены с реальными выгрузками платформы.
